一个统一的浏览器界面，一次提问，同时向 **DeepSeek**、**阿里云通义千问** 等多个国产 AI 发送请求，并以固定卡片**流式实时展示**回答。

## ✨ 功能亮点
- 🧠 多模型并发提问，答案实时流式输出
- 📦 卡片固定高度，内容溢出可滚动，不撑开页面
- 🪟 点击卡片弹出模态框，Markdown 渲染完整回答
- 🛑 随时中断回答
- 🚀 双击 `start.bat` 一键启动前后端
- 📋 后端错误日志分离，问题排查更方便
- 🎨 错误区分：余额不足/其他错误，界面自动变灰提示

## 🛠 技术栈
- **前端**：React 19 + Vite 8 + Tailwind CSS v4
- **后端**：Node.js + Express
- **AI 调用**：OpenAI SDK（兼容接口）
- **启动管理**：concurrently（一键启动前后端）
浏览器打开 http://localhost:5173，开始提问吧！
